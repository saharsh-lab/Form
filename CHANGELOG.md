# Changelog

## 0.1.0 (unreleased)

The first complete build, developed in seven phases.

- **Foundation:** SwiftData models with snapshots, a design system, four tabs, deep links, haptics, and the FormCore calculation package.
- **Nutrition:** user-defined foods, ranked search, a food diary with undo, saved meals, and daily targets with history.
- **Workouts:** routines, the active workout with warm-up and drop sets, a date-based rest timer, pause and resume, personal records, and history editing.
- **Progress:** Swift Charts for consistency, exercise history, volume, body measurements and nutrition trends, with range selection and point inspection.
- **Widgets:** Home Screen and Lock Screen widgets, the workout Live Activity, and App Intents with Siri phrases.
- **Data:** JSON and CSV export, delete all data, an optional daily logging reminder, Reduce Motion support, and UI tests.
- **Release:** CI on GitHub Actions, privacy manifests, release and QA documentation.
